### Project Overview
Decodelab tasks is an Ecommerce Sales tasks that analyzes e-commerce sales to uncover trends in sales performance, customer behavior, product performance, and operatioal efficiency using Microsoft Excel.
### Dataset Description
The dataset contails order-level transaction records including: order ID, customer ID, product name, quantity, unite proce, total proce, payment method, order status, items in cart, coupon code, referral source, and shipping address.
### Tools Used
- Microsoft Excel
  For: - Data cleaning
  - Pivot tables
  - Pivot charts
  - Conditional formatting
  - Statistical funtions like QUARTILE and IF, and IQR-based outlier detection.
### Data Cleaning and Transformation
Checked for missing values, removed duplicates, standardized Text formats, ensured correct data types, flagged outliers using IQR, formatted currency columns, amd trimmed unnecessary spaces.

### Exploratory Data Analysis (EDA)
The analysis focused on key questions such as: 
- Which products generated most of the revenue?
- What are the preferred payment methods?
- Which referral sources drive the most customers?
- What percentage of orders are completed versus cancelled?
- Are there abnormal order values or purchase quantities?
